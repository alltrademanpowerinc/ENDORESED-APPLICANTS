# Public Submission Instructions — Endorsed Applicants

This publicly-published file explains how to submit a candidate or applicant. It is intentionally accessible and avoids publishing any candidate Personal Identifiable Information (PII).

## Overview
This page explains how to submit a candidate or an application. It is published publicly so people without GitHub accounts can view it.

## How to submit
1. Complete the submission form: https://alltrademanpowerinc.github.io/ENDORESED-APPLICANTS-PUBLIC/apply
   - If you do not have a form, email submissions to: alltrademanpowerinc.recruitment@gmail.com
2. Required information:
   - Candidate full name
   - Candidate contact email and phone
   - Position applied for (job ID or title)
   - Resume/CV (PDF preferred; plain text acceptable)
   - Brief notes or referral information (optional)
3. Attachments
   - Upload files in PDF, DOCX, or plain text. Avoid scanned images of text-only documents.
   - For each uploaded file, include a short descriptive filename and a one-line description.
4. Confirmation
   - You will receive a confirmation email within 24 hours of submission.

## Accessibility & accommodations
- If you need these instructions or the submission form in an alternate format (large print, audio, translation, or via phone), contact: alltrademanpowerinc.recruitment@gmail.com
- Preferred file formats: tagged PDF or plain text. If sending images of text is unavoidable, also provide a plain text transcript.
- Use clear headings and short paragraphs. Provide descriptive link text instead of “click here.”

## Privacy & security
- Do NOT include sensitive personal information (SSN, government IDs) in the initial submission.
- Resumes and attachments are stored securely and accessed only by authorized recruiting staff.
- If you need to submit sensitive documents, contact alltrademanpowerinc.recruitment@gmail.com for secure transfer options.

## Questions or problems
- For help submitting, please email alltrademanpowerinc.recruitment@gmail.com or view the project README: https://github.com/alltrademanpowerinc/ENDORESED-APPLICANTS/blob/ENDORSED_APPLICANT_TRACKING_SYSTEM/README.md
